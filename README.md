Hi! I'm Luiz, a software engineer originally from Brazil and now based in the US.

After a long career in big tech, I stepped away to build things on my own
terms. These days I'm exploring where AI agents, virtualization and infrastructure meet. I care about
local-first software, declarative systems, and tools that keep your data private by default. I'm
especially interested in how strong primitives like VMs and WebAssembly sandboxes can let autonomous
tools do useful work while users stay in control.

I write about what I'm building at **[l9o.dev](https://l9o.dev)**.

### What I'm working on

Some projects I maintain:

- **[uptix](https://github.com/luizribeiro/uptix)**: pins and updates external dependencies, like Docker images, in NixOS configurations.
- **[agentix](https://github.com/luizribeiro/agentix)**: a single Nix flake for popular AI coding CLIs.
- **[weblounge.org](https://weblounge.org)**: a small, invite-only IRC network. If you'd like an invite, [send me an email](mailto:contact@l9o.dev).

Coming soon: **[wasm-junction](https://github.com/luizribeiro/wasm-junction)**, an ergonomic Rust
framework for building applications out of WebAssembly components. It runs natively on Wasmtime and
in the browser. It's still early and the API isn't stable yet.

When something I depend on breaks, I try to fix it upstream. Recently that has meant
[macOS support for microvm.nix](https://github.com/microvm-nix/microvm.nix) through the vfkit
hypervisor, plus fixes in [jco](https://github.com/bytecodealliance/jco),
[russh](https://github.com/Eugeny/russh) and [nixpkgs](https://github.com/NixOS/nixpkgs).

### In a previous life

I spent 13 years at Facebook and Instagram, slowly working my way down the stack. I started in web
frontend, on one of the first teams to run React in production, and ended up in privacy
infrastructure that helps thousands of engineers handle user data responsibly.

Some past projects I'm no longer maintaining:

- **[mariner](https://github.com/luizribeiro/mariner)**: a web interface for MSLA resin 3D printers based on Chitu controllers (Elegoo, Phrozen). It started as a Raspberry Pi Zero wired to my printer's serial port ([writeup](https://l9o.dev/posts/controlling-an-elegoo-mars-pro-remotely/)).
- **[vim-cooklang](https://github.com/luizribeiro/vim-cooklang)** and **[py-cooklang](https://github.com/luizribeiro/py-cooklang)**: a vim plugin and a Python parser for [Cooklang](https://cooklang.org/), a markup language for recipes.
- **[gython](https://github.com/luizribeiro/gython)**: part of the Gephi Scripting Plugin I built for Google Summer of Code 2011, a Jython fork with operators for manipulating graphs.
- **[QMK](https://github.com/qmk/qmk_firmware)**: I added support for ps2avrGB keyboards to the keyboard firmware.
